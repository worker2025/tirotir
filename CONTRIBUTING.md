# Contributing to Tirotir

Thank you for your interest in contributing to Tirotir / تیروتیر.

Tirotir is an open-source Persian programming language project. Contributions
are welcome when they improve the language, implementation, documentation,
testing, tooling, or educational ecosystem.

## Before Contributing

Please:

1. Read the project documentation.
2. Check existing issues and pull requests.
3. Keep changes focused and understandable.
4. Add or update tests when appropriate.
5. Update documentation when behavior or public interfaces change.
6. Respect the licenses of third-party code and dependencies.

## Developer Certificate of Origin

Contributors are encouraged to sign their commits using:

```text
git commit -s
```

This indicates that the contributor agrees to the Developer Certificate of
Origin (DCO) applicable to the contribution.

## Pull Requests

A pull request should normally include:

* a clear description of the change;
* relevant tests;
* documentation updates where necessary;
* no unnecessary unrelated changes;
* appropriate attribution for third-party material.

## Compatibility

Changes to the language syntax, semantics, standard library, or public APIs
should be documented clearly.

Breaking changes should be identified explicitly.

## Third-Party Code

Do not copy code, documentation, images, fonts, or other materials into the
project unless their license permits the intended use.

Preserve required copyright and license notices.

## Questions

For project-specific questions, use the project's official communication
channels or GitHub issue tracker where appropriate.
