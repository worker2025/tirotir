# Tirotir Authors

## Creator and Lead Developer

**Daryoush Alipour**

Creator and original author of the Tirotir / تیروتیر Persian programming
language.

Official project:

* Website: https://tirotir.ir/
* Repository: https://github.com/worker2025/tirotir
* DOI: https://doi.org/10.5281/zenodo.22874866

Tirotir was created as a Persian programming language project with the goal of
enabling programming and computer education using Persian syntax and
terminology.
