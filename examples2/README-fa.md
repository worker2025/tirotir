# مجموعهٔ آموزشی Examples برای Tirotir 1.1.0

این مجموعه روی یک workspace مستقل ساخته شده است و نمونه‌های baseline اصلی را حذف یا تغییر نمی‌دهد. همهٔ فایل‌های جدید پسوند رسمی `.t` دارند.

هر نمونه با syntax موجود Tirotir نوشته شده است. نمونه‌های متنی و صوتی با مفسر فعلی قابل اجرای واقعی هستند. نمونه‌های GUI به Tkinter و desktop نیاز دارند و در محیط headless فقط check و diagnostic محیطی دارند. Graphics این مجموعه static SVG و live scene است؛ animation زمان‌مند در این نسخه ساخته نشده است.

مدل شیء و کلاس در نسخهٔ فعلی زبان وجود ندارد؛ بنابراین مثال جعلی برای آن اضافه نشده است.

## دسته‌ها

- `basics`: چاپ متن و شروع کار
- `variables`: متغیر و مقداردهی
- `input`: ورودی کاربر
- `output`: خروجی و قالب‌بندی ساده
- `math`: محاسبات
- `conditions`: شرط
- `loops`: حلقه و تکرار
- `lists`: فهرست
- `dictionaries`: فرهنگ
- `functions`: تابع و ترکیب چند مفهوم
- `gui`: نمونه‌های GUI با primitiveهای واقعی فعلی
- `graphics`: شکل‌های static با SVG
- `audio`: نت‌ها و ملودی‌های کوتاه آموزشی

نتیجهٔ اجرای همهٔ فایل‌ها در `VALIDATION-fa.md` ثبت می‌شود.
