# GUI

این نمونه‌ها فقط از primitiveهای واقعی فعلی Tirotir استفاده می‌کنند: پنجره، برچسب، دکمه، ورودی، چک‌باکس، فهرست، منوی انتخاب، متن چندخطی و نوار لغزش.

در نسخهٔ فعلی callback و event برای دکمه‌ها وجود ندارد؛ بنابراین نمونه‌ها ساخت رابط را نشان می‌دهند و قابلیت جعلی برای محاسبهٔ زنده یا واکنش دکمه اضافه نشده است. روی Windows یا desktop اجرا کنید.
