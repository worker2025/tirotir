# قابلیت‌های خارج از این bundle

این bundle عمداً syntax ساختگی برای قابلیت‌های تأییدنشده ندارد.

- `network` و `project-files` primitive عمومی زبان نیستند؛
- LSP و debugger در این release ارائه نشده‌اند؛
- syntax عمومی event و animation زمان‌مند در این bundle ادعا نمی‌شوند؛
- پخش سخت‌افزاری صدا و فعال‌سازی واقعی VS Code در harness headless تأیید نمی‌شوند؛
- capability enforcement sandbox کامل سیستم‌عامل نیست.
