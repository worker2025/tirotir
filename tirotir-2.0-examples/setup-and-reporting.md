# نصب و گزارش خطا

نام distribution در pip برابر `tirotir` و فرمان اجرایی برابر `tirotir` است. در این release، PyPI هنوز distribution عمومی `tirotir` ندارد؛ از wheel رسمی GitHub Release یا source archive استفاده کنید.

برای گزارش خطا این اطلاعات را بفرستید:

- SHA یا نسخهٔ package؛
- سیستم‌عامل و `python --version`؛
- خروجی `python -m pip show tirotir`؛
- فرمان کامل و خروجی harness؛
- مثال کمینهٔ بازتولیدکننده؛
- capabilityهای فعال.

اطلاعات محرمانه، token، کلید و رمز را ارسال نکنید.
