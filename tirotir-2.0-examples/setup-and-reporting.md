# نصب و گزارش خطا

نام distribution در pip برابر `tirotir` و فرمان اجرایی برابر `tirotir` است. نسخهٔ پایدار `2.0.2` در PyPI موجود است و نصب آن با `python -m pip install tirotir==2.0.2` انجام می‌شود؛ wheel رسمی GitHub Release نیز برای نصب آفلاین یا توسعه قابل استفاده است.

برای گزارش خطا این اطلاعات را بفرستید:

- SHA یا نسخهٔ package؛
- سیستم‌عامل و `python --version`؛
- خروجی `python -m pip show tirotir`؛
- فرمان کامل و خروجی harness؛
- مثال کمینهٔ بازتولیدکننده؛
- capabilityهای فعال.

اطلاعات محرمانه، token، کلید و رمز را ارسال نکنید.
