# گزارش کنترل کیفیت تیروتیر ۱٫۰

## نتیجه

در محیط Linux با Python 3.12، بسته با `pip install -e .` نصب شد و فرمان `tirotir version` خروجی `Tirotir 1.0.0` داد.

## تست‌ها

| بخش | نتیجه |
|---|---:|
| تست‌های پایهٔ lexer/parser/interpreter | ۱۰۶ موفق |
| تست‌های پذیرش قابلیت‌های کامل‌شده | ۷ موفق |
| مجموع تست‌های خودکار | **۱۱۳ موفق** |
| برنامه‌های نمونه | **۷۱ از ۷۱ موفق** |
| سناریوی رسمی نمره‌ها | خروجی «عالی است» |
| انتساب با `=` | موفق؛ خروجی ۱۵ و ۱۶ |
| بررسی syntax و AST JSON | موفق |

## قابلیت‌های نهایی

انتساب فارسی و نمادی، فهرست، فرهنگ، اندیس‌گذاری و تغییر عضو، شرط، حلقه، تابع، recursion، ورودی، کامنت، تبدیل نوع، خطاهای فارسی و حفاظت حلقهٔ بی‌نهایت آزمایش شده‌اند.

## محدودیت‌های شناخته‌شده

مفسر نسخهٔ ۱ دسترسی آزاد به شبکه، shell، import پایتون و filesystem ندارد. برای امنیت، ورودی و خروجی از API کنترل‌شدهٔ CLI استفاده می‌کنند. installer بومی `.exe` یا `.msi` در این انتشار ساخته نشده و نصب از طریق Python package انجام می‌شود.

## نصب نهایی

```bash
python -m pip install .
tirotir version
tirotir run examples/00_official_program.t
```
