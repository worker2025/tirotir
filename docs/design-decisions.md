# تصمیم‌های طراحی تیروتیر

- متن با `-...-` مشخص می‌شود و خط تیرهٔ درون متن با `\\-` گریز داده می‌شود.
- تورفتگی چهار فاصله‌ای استاندارد است و ترکیب تورفتگی‌های ناسازگار خطا می‌دهد.
- مفسر مستقیم انتخاب شده تا رفتار آموزشی شفاف و امن باشد.
- اجرای پوسته، شبکه، import و دسترسی آزاد به فایل عمداً ارائه نشده است.
- عبارت‌های مقایسهٔ فارسی به عملگرهای نمادی نرمال می‌شوند.

# نصب و CLI

با `pip install .` نصب کنید. `run` اجرا، `check` بررسی، `ast` خروجی JSON، `format` قالب‌بندی و `repl` آزمون تعاملی است.

# معماری

Source → tokenizer/indentation → parser/AST → interpreter. هر node داده‌ای است و با `ast_json` قابل تبدیل به JSON است.
