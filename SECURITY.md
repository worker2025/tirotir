# Security Policy

## Supported Versions

Security fixes are applied to actively maintained versions of Tirotir.

Because Tirotir is an evolving project, users should generally use the latest
stable release when possible.

## Reporting a Vulnerability

Please do not publicly disclose an exploitable security vulnerability before
the project has had a reasonable opportunity to investigate it.

Report security vulnerabilities privately through the project's available
private security-reporting mechanism or official project contact channel.

When reporting a vulnerability, please include:

* affected version;
* affected component;
* steps to reproduce;
* expected behavior;
* actual behavior;
* potential impact; and
* any relevant logs, screenshots, or proof-of-concept information.

## Response

The project will review valid security reports and, where appropriate, work
toward a fix and coordinated disclosure.

Please avoid including passwords, private keys, personal information, or other
unnecessary sensitive data in vulnerability reports.

## Scope

This policy applies to security issues affecting the official Tirotir project,
including its source code, interpreter/compiler components, official tooling,
and project infrastructure where applicable.

Third-party dependencies may have their own security-reporting procedures.
